# 未来思路：基于 FAA 注册数据的航空经济与产业状态分析

本文档整理项目后续可以拓展的研究方向。核心思路是：从 FAA 注册数据出发，不只分析飞机本身，而是把飞机注册、机场基础设施、航班运行、安全事件、天气、地区经济和企业信息关联起来，用微观数据间接观察美国航空经济状态、区域航空产业状态和航空资产流动特征。

## 核心切入点

FAA 注册数据可以视为航空资产的“身份证”。它包含飞机注册号、Mode S Code、制造商、型号、制造年份、注册人、注册地、证书状态等信息。

由此可以继续追问：

- 飞机登记在哪里，实际活动在哪里？
- 哪些地区航空资产密度高？
- 哪些地区机队更老旧或更新更快？
- 哪些机场承受了超出基础设施水平的活动压力？
- 安全事件、天气、鸟击、延误是否能反映航空系统压力？
- 企业、信托、租赁公司等注册主体是否体现航空资产金融化？

这些问题都可以避免局限于“飞机品牌”或“单架飞机”，转向区域经济、产业结构和系统运行状态。

## 重点研究方向

### 1. 注册地偏离分析

核心问题：

飞机登记在哪里，实际活动在哪里？如果注册地和主要活动地不同，这种偏离是否反映了税务、企业注册便利、航空资产配置或运营网络？

可用数据：

- FAA 注册地
- OpenSky 活动地点
- NASR 机场位置
- Census 州/县经济数据

可构造指标：

```text
注册地偏离率 = 实际主要活动州 != FAA 注册州 的飞机数量 / 可观测飞机数量
```

可分析现象：

- 哪些州更像“航空资产登记地”？
- 哪些州更像“航空资产实际使用地”？
- 企业、LLC、Trust 注册主体是否更容易出现偏离？
- 高价值飞机和普通通航飞机的偏离模式是否不同？

### 2. 通用航空活跃度与地方经济

核心问题：

小飞机、小机场是否能反映美国地方经济活力？

可用数据：

- FAA 注册飞机
- NASR 机场
- Census 人口、收入、产业结构
- OpenSky 活动观测

可构造指标：

- 每万人注册飞机数
- 每县机场密度
- 每 GDP 注册飞机数
- 喷气机占比
- 单发活塞飞机占比
- 新机占比
- 老旧飞机占比

可分析现象：

- 农业州、能源州、旅游州、金融州的航空资产结构差异
- 商业航班不强但通航活跃的地区
- 偏远地区是否更依赖通用航空
- 飞行训练、医疗转运、企业出行是否形成区域集群

### 3. 航空资产更新能力

核心问题：

机龄结构能否间接体现地区航空投资能力和产业状态？

可用数据：

- FAA 制造年份
- 注册地
- 机型类别
- NTSB/ASRS/SDR 安全或维护文本

可构造指标：

```text
老旧飞机占比 = 机龄 >= 30 年飞机 / 全部飞机
新机占比 = 机龄 <= 5 年飞机 / 全部飞机
平均机龄 = 当前年份 - 制造年份
```

可分析现象：

- 哪些州航空资产更新更快？
- 老旧飞机是否集中在特定地区或机场类型？
- 老旧飞机是否更常出现在维护、安全事件文本中？
- 新机占比是否和地区收入、产业结构相关？

### 4. 机场基础设施承压

核心问题：

机场数量、跑道长度和服务能力是否匹配当地航空活动？

可用数据：

- NASR 机场/跑道
- FAA 注册飞机
- OpenSky 活动
- BTS 延误
- Census 地区经济

可构造指标：

- 注册飞机数 / 机场数
- 活动航班数 / 跑道长度
- 高性能飞机活动量 / 适配跑道能力
- 小机场承压指数

可分析现象：

- 小机场是否承担大量通航和商务飞行？
- 某些地区是否存在航空基础设施缺口？
- 跑道条件是否限制地区航空活动？
- 机场能力与地方经济发展是否匹配？

### 5. 航空系统运行压力与韧性

核心问题：

哪些机场或地区对天气、拥堵、空域压力更敏感？

可用数据：

- BTS 延误/取消
- NOAA 天气
- NASR 机场基础设施
- FAA 注册数据
- Wildlife Strike

可构造指标：

- 天气延误占比
- 取消率
- 平均到达/离港延误
- 延误传播中心性
- 鸟击损失指数
- 机场运行压力指数

可分析现象：

- 哪些枢纽对全国延误传播影响大？
- 哪些机场天气敏感度高？
- 哪些区域航空系统韧性较弱？
- 基础设施是否能解释延误和恢复能力？

### 6. 航空安全与维护压力

核心问题：

安全报告和事故叙述能否反映机队、地区或机场的隐性压力？

可用数据：

- NTSB 事故数据
- NASA ASRS 报告
- FAA 注册数据
- NOAA 天气
- NASR 机场

可分析现象：

- 事故主题是否和机龄、机型、机场类型相关？
- 训练、进近、通信、机械、天气等主题是否呈现区域差异？
- 相似事故或近失事件是否集中在某类机场或环境？
- 安全报告能否作为运行压力的早期信号？

适合 Milvus 的方向：

- 事故叙述向量化
- ASRS 报告向量化
- 机场风险画像向量化
- 相似案例检索

### 7. 鸟击与生态运行风险

核心问题：

机场周边生态环境如何影响航空运行成本和安全？

可用数据：

- FAA Wildlife Strike
- NASR 机场
- NOAA 天气
- FAA 注册/机型
- BTS 航班量

可构造指标：

- 鸟击次数 / 航班量
- 鸟击损失金额
- 季节性鸟击指数
- 机场生态风险指数

可分析现象：

- 哪些机场鸟击成本最高？
- 鸟击是否有明显季节性？
- 天气、迁徙季节、机场周边环境是否影响鸟击？
- 机场治理能力是否能从风险变化中体现？

### 8. 航空资产金融化和登记主体网络

核心问题：

飞机注册主体是否能反映航空资产金融化、企业结构和租赁网络？

可用数据：

- FAA 注册人字段
- SEC EDGAR 公司信息
- 注册地
- 机型和机龄

可分析主体类型：

- 个人
- 公司
- LLC
- Trust
- Bank
- Leasing
- Inc

可分析现象：

- 高价值飞机是否更常注册到 LLC 或 Trust？
- 哪些州 LLC/Trust 注册比例更高？
- 企业机队是否集中在总部州，还是运营州？
- 航空租赁和金融主体是否形成网络中心？

## 总体表达

项目后续可以定位为：

> 基于公开航空注册、运行、安全、机场和地区经济数据，构建美国航空经济微观观察指标体系。通过飞机注册、活动偏离、机场承压、资产更新、安全事件、天气影响和企业网络等代理变量，分析区域航空产业状态与航空经济结构。

这个方向的优势是“见微知著”：不直接依赖宏观报告，而是从公开微观数据构建可解释的航空经济观察框架。

本次临时文件中已经具备了三个可以直接扩展现有 FAA/OpenSky 分析的数据库，以及一个 OpenSky Trino 历史轨迹导出目录：

| 临时数据 | 已确认内容 | 数据粒度 | 对现有系统的价值 |
| --- | --- | --- | --- |
| `28DaySubscription_Effective_2026-04-16.zip` | FAA NASR 28 天周期数据，含 `APT.txt`、`NAV.txt`、`AWOS.txt`、`TWR.txt` 等 | 机场、跑道、导航台、气象观测、塔台与通信设施 | 把“飞机在哪里注册、在哪里飞”落到具体机场和基础设施承载能力 |
| `DB28SEG.FD.WAC.202503.202602.REL01.05MAY2026.zip` | BTS / DB28 航段统计，`db28seg...asc` 共约 114,968 行 | 航段、月份、起降城市/机场、承运人、距离、客货邮、班次/座位等 | 补充商业航空流量和机场/航线经济强度 |
| `the Census of US Civil Aviation Accidents avall.zip` | NTSB Access 数据库，核心表包括 `events`、`aircraft`、`narratives`、`Findings`、`Flight_Crew`、`engines`、`injury` | 事故/事件、涉事航空器、人员、天气、叙述文本、原因发现 | 构建安全风险、事故主题、机型/机龄/机场风险画像 |
| `trino-tables Sun 1 March 2026 000000 UTC/` | OpenSky Trino parquet 历史轨迹，两份文件约 102,695 条航迹 | `icao24`、`firstSeen`、`lastSeen`、估计起降机场、轨迹点列 | 比当前实时快照更适合分析实际活动地、机场出现频率和注册地偏离 |

现有程序中的两个业务数据库表是：

- `faa_aircraft`：当前约 313,048 条 FAA 注册飞机记录，核心连接键是 `mode_s_code_hex`、`n_number`、注册人、注册州、制造年份。
- `opensky_states`：当前约 6,817 条 OpenSky 实时状态记录，其中约 6,740 条有经纬度，约 971 条可通过 `icao24 = mode_s_code_hex` 匹配到 FAA 注册飞机。

`users` 和 `sessions` 只服务登录，不进入航空分析主题。

### 一、数据连接关系

可以把 FAA 注册数据作为航空资产主表，把 OpenSky 实时/历史轨迹作为活动观测，把 NASR 作为机场基础设施，把 BTS 作为商业流量，把 NTSB 作为安全事件。

核心连接键如下：

| 连接对象 | 建议连接键 | 说明 |
| --- | --- | --- |
| FAA Registry -> OpenSky | `faa_aircraft.mode_s_code_hex = OpenSky.icao24` | 识别注册飞机的实际飞行活动 |
| FAA Registry -> NTSB aircraft | `faa_aircraft.n_number = NTSB.aircraft.regis_no` | 连接事故中涉事飞机和注册/机龄/所有人 |
| OpenSky Trino -> NASR Airport | `estDepartureAirport` / `estArrivalAirport` / `airportOfDeparture` / `airportOfDestination` 对接 NASR 机场标识 | 形成机场起降和活动网络 |
| NTSB events -> NASR Airport | `events.ev_nr_apt_id` 或机场名/经纬度邻近匹配 | 连接事故地点、机场设施和天气条件 |
| BTS DB28SEG -> NASR Airport | 起降机场代码、城市市场代码 | 连接商业航线量和机场基础设施 |
| NASR Airport -> 地区 | 州、县、经纬度空间匹配 | 形成州/县级航空活跃度和承压指标 |

其中最重要的主线是：

```text
FAA 注册飞机
  -> Mode S / icao24 匹配 OpenSky 活动
  -> 起降机场匹配 NASR 基础设施
  -> 机场/航段匹配 BTS 商业流量
  -> N-number 匹配 NTSB 事故航空器
  -> 事故叙述进入 Milvus，实体关系进入 Neo4j
```

### 二、各临时数据库的分析价值

#### 1. NASR：机场基础设施承载能力

NASR 的 `APT.txt` 是最关键文件，已确认包含机场记录、跑道记录和备注记录。其中机场字段可取得机场标识、机场所有权、设施用途、机场参考点经纬度；跑道记录可取得跑道长度、宽度、铺装、端点坐标等。

适合构造：

- 机场数量、跑道数量、最长跑道、平均跑道长度。
- 公共/私人机场占比。
- 每州/每县机场密度。
- 小机场承压指数：`OpenSky 起降/出现次数 / 跑道能力`。
- 基础设施适配度：商务喷气机或高性能飞机活动是否集中在跑道条件不足的机场。

可视化：

- 美国机场基础设施分布地图。
- 跑道长度分级符号图。
- 州/县级机场密度热力图。
- 机场承压排行榜。

#### 2. BTS DB28SEG：商业航空流量和航线经济

DB28SEG 是按月/航段记录的商业航空统计数据。样例行中可以看到年份、月份、起飞机场/城市、到达机场/城市、承运人、距离、服务类型、班次、客货邮等指标。

适合构造：

- 航段客运量、货运量、邮件量。
- 起降机场商业流量。
- 航线强度和季节性。
- 枢纽机场中心性。
- 商业航空和通用航空的互补关系：商业航班弱但注册飞机/小机场强的地区，可能更依赖通航。

可视化：

- OD 航线流向图。
- 机场客货流量气泡图。
- 月度航段流量趋势图。
- 商业航空覆盖不足地区叠加通航活跃度地图。

#### 3. NTSB：安全事件、事故文本和风险画像

NTSB 的 `avall.mdb` 已确认可读取，核心记录量如下：

| 表 | 记录量 | 作用 |
| --- | ---: | --- |
| `events` | 30,646 | 事故/事件时间、地点、机场、天气、伤亡、经纬度 |
| `aircraft` | 31,170 | 涉事飞机注册号、制造商、型号、年份、运营人、飞行类型 |
| `narratives` | 28,117 | 事故经过、事实、原因叙述文本 |
| `Findings` | 71,844 | 原因/因素发现 |
| `Flight_Crew` | 32,053 | 机组年龄、资质、伤害等级等 |
| `engines` | 28,171 | 发动机类型、型号、时间等 |
| `injury` | 176,738 | 人员伤害统计 |

适合构造：

- 事故率画像：按机型、机龄、注册主体、机场类型、州/县统计。
- 天气相关事故：结合 `events` 中能见度、风、温度、METAR 等字段。
- 机场附近事故密度：用 `ev_nr_apt_id` 或经纬度匹配 NASR 机场。
- 叙述文本主题：进近、低能见度、失控、机械、训练、通信、人因等。
- 相似事故检索：将 `narratives.narr_accp`、`narr_accf`、`narr_cause` 向量化后进入 Milvus。

可视化：

- 事故点位地图。
- 机龄-事故数量/严重度矩阵。
- 事故主题桑基图。
- 机场风险雷达图。
- 相似案例检索结果列表和相似度分布。

#### 4. OpenSky Trino parquet：历史活动轨迹

当前程序中的 OpenSky 只是实时快照，适合展示“此刻在哪里”；Trino parquet 是历史航迹，适合分析“长期在哪里活动”。两份 parquet 已确认字段包括：

```text
icao24
firstSeen
lastSeen
estDepartureAirport
estArrivalAirport
callsign
track
serials
estDepartureAirportHorizDistance
estDepartureAirportVertDistance
estArrivalAirportHorizDistance
estArrivalAirportVertDistance
airportOfDeparture
airportOfDestination
takeoffLandingInfo
```

适合构造：

- 飞机主要活动机场和主要活动州。
- 注册地偏离率。
- 机场起降/出现频率。
- 通航短途飞行和商业航线区分。
- 航迹异常：绕飞、低空、短时多段、重复训练航线。

可视化：

- 航迹热力图。
- 单机活动轨迹回放。
- 注册州 -> 活动州流向图。
- 机场 OD 网络图。

### 三、Milvus 与 Neo4j 的明确分工

#### Milvus：只保存语义向量，不保存主关系

Milvus 应用于“相似性”和“语义检索”，不要承担实体关系数据库的职责。

建议向量集合：

| Milvus Collection | 向量对象 | metadata |
| --- | --- | --- |
| `ntsb_narrative_embeddings` | NTSB 事故经过、事实、原因文本 | `ev_id`、`Aircraft_Key`、`n_number`、`event_date`、`airport_id`、`state`、`injury_level` |
| `airport_risk_profile_embeddings` | 机场风险画像文本 | `airport_id`、`state`、`runway_count`、`traffic_level`、`accident_count` |
| `aircraft_profile_embeddings` | 飞机画像文本：注册、机龄、机型、活动地、事故历史 | `icao24`、`n_number`、`owner_type`、`year_mfr` |
| `county_aviation_profile_embeddings` | 县/州级航空画像 | `state`、`county`、`airport_density`、`activity_index` |

典型问题：

- “找出和低能见度进近偏航类似的事故。”
- “某机场的风险画像最像哪些机场？”
- “某架飞机的活动模式和事故历史像哪些飞机？”
- “某类事故在什么机场、机型、天气条件下反复出现？”

#### Neo4j：保存实体关系和路径

Neo4j 应保存跨数据源的实体网络，用于路径、社区、中心性和传播分析。

建议节点：

```text
Aircraft
Owner
Manufacturer
AircraftModel
Airport
Runway
State
County
FlightObservation
FlightSegment
Accident
Narrative
Finding
WeatherCondition
Carrier
Route
```

建议关系：

```text
(Aircraft)-[:REGISTERED_IN]->(State)
(Aircraft)-[:OWNED_BY]->(Owner)
(Aircraft)-[:HAS_MODEL]->(AircraftModel)
(AircraftModel)-[:MADE_BY]->(Manufacturer)
(Aircraft)-[:OBSERVED_ON]->(FlightObservation)
(FlightObservation)-[:DEPARTED_FROM]->(Airport)
(FlightObservation)-[:ARRIVED_AT]->(Airport)
(Airport)-[:LOCATED_IN]->(County)
(Airport)-[:HAS_RUNWAY]->(Runway)
(Route)-[:FROM]->(Airport)
(Route)-[:TO]->(Airport)
(Route)-[:OPERATED_BY]->(Carrier)
(Accident)-[:INVOLVES]->(Aircraft)
(Accident)-[:OCCURRED_NEAR]->(Airport)
(Accident)-[:HAS_FINDING]->(Finding)
(Accident)-[:HAS_NARRATIVE]->(Narrative)
(Accident)-[:UNDER_WEATHER]->(WeatherCondition)
```

典型问题：

- 从某个注册主体出发，它控制了哪些飞机，这些飞机主要活动在哪些机场，是否涉及事故？
- 哪些机场在航线网络中是高中心性节点，同时事故/延误/天气风险也偏高？
- 哪些州是“注册中心”，哪些州是“实际使用中心”？
- Trust、LLC、Bank 等主体是否形成航空资产网络中心？

### 四、辅助决策系统的分析主题

不做项目开发时，可以把成果定义为“数据分析与辅助决策系统方案”，由指标、图表、风险解释和决策建议组成。

#### 主题 A：航空资产注册地偏离

问题：

飞机注册地和实际活动地是否一致？偏离是否与 Trust、LLC、Bank 等主体有关？

关键数据：

- FAA `faa_aircraft`
- OpenSky Trino 历史轨迹
- NASR 机场位置

核心指标：

```text
注册地偏离率 = 主要活动州 != FAA 注册州 的飞机数量 / 可观测飞机数量
州际净流入 = 活动在本州但注册在外州的飞机 - 注册在本州但主要活动在外州的飞机
主体偏离差异 = LLC/Trust/Bank 偏离率 - 个人注册偏离率
```

可视化：

- 注册州 -> 活动州 Sankey 图。
- 州级偏离率热力图。
- 注册主体类型偏离率柱状图。
- 单架飞机活动轨迹和注册信息联动视图。

辅助决策：

- 识别航空资产登记中心。
- 识别实际航空需求强但本地注册资产少的地区。
- 判断地方机场与航空经济政策是否吸引真实运营，而不仅是登记。

#### 主题 B：机场基础设施承压

问题：

机场、跑道、塔台、气象设施是否能支撑实际活动和商业航段流量？

关键数据：

- NASR `APT.txt`、`TWR.txt`、`AWOS.txt`
- OpenSky Trino 轨迹
- BTS DB28SEG

核心指标：

```text
机场活动强度 = 起降/出现次数
跑道承压指数 = 机场活动强度 / 最长跑道长度
商业流量承压 = BTS 客货邮流量 / 跑道与塔台能力
气象设施缺口 = 高活动机场是否缺少 AWOS/ASOS 或塔台服务
```

可视化：

- 机场承压气泡地图。
- 跑道长度 vs 活动量散点图。
- 商业流量 vs 通航活动双轴图。
- 高承压机场 Top N 排行榜。

辅助决策：

- 识别可能需要基础设施投资的机场。
- 判断小机场是否承担了超出基础设施等级的活动。
- 为机场扩建、跑道改造、气象设备部署提供优先级。

#### 主题 C：安全风险与相似案例检索

问题：

事故、机型、机龄、机场设施、天气和飞行活动之间有什么可解释关系？

关键数据：

- NTSB `events`、`aircraft`、`narratives`、`Findings`
- FAA `faa_aircraft`
- NASR 机场/跑道
- OpenSky 活动轨迹
- Milvus 文本向量
- Neo4j 事故关系图

核心指标：

```text
机龄风险画像 = 事故涉事飞机机龄分布 / FAA 全量机龄分布
机场事故密度 = 机场附近事故数量 / 机场活动强度
天气相关事故占比 = 带有天气因素或恶劣气象条件的事故 / 总事故
相似案例风险 = Milvus Top-K 相似事故的严重度加权平均
```

可视化：

- 事故点位与机场叠加地图。
- 机龄-事故严重度热力矩阵。
- 事故主题词云/主题流图。
- Neo4j 事故-飞机-机场-天气关系网络。
- Milvus 相似事故检索结果卡片。

辅助决策：

- 为机场安全审计提供重点对象。
- 为老旧机队、训练机场、复杂天气机场建立风险提示。
- 在新事故出现时快速检索历史相似案例和常见原因。

#### 主题 D：区域航空活跃度与产业画像

问题：

哪些州/县体现出更强的通航、商务航空、商业航空或航空资产金融化特征？

关键数据：

- FAA 注册飞机
- OpenSky 历史活动
- NASR 机场基础设施
- BTS 商业航段
- NTSB 安全事件

核心指标：

```text
航空活跃度指数 = 标准化(注册飞机数 + 活动飞机数 + 机场数 + 航段流量)
资产金融化指数 = LLC/Trust/Bank 注册占比 + 跨州偏离强度
基础设施充足度 = 机场/跑道能力 / 活动强度
区域安全压力 = 事故数量或严重度 / 活动强度
```

可视化：

- 州/县级航空活跃度地图。
- 区域雷达图：资产、活动、商业流量、基础设施、安全。
- 州级聚类散点图。
- 高金融化注册主体网络图。

辅助决策：

- 判断区域航空产业类型：通航型、商务航空型、商业枢纽型、登记中心型、风险承压型。
- 辅助地方航空经济规划。
- 识别航空资产多但真实活动弱、或真实活动强但基础设施弱的地区。

### 五、推荐可视化页面结构

不开发项目时，仍可把可视化成果设计为 5 个分析看板：

1. 总览看板：FAA 注册量、OpenSky 活动量、NASR 机场量、BTS 航段量、NTSB 事故量。
2. 地图看板：机场、航迹、事故、航线流向、州/县热力图。
3. 网络看板：Neo4j 展示飞机-注册人-机场-事故-航线关系。
4. 风险看板：机场承压、安全事件、天气相关事故、相似案例。
5. 决策看板：按机场、州、注册主体输出风险/机会评分和优先级建议。

图表类型建议：

| 分析对象 | 推荐图表 |
| --- | --- |
| 机场/事故/活动 | Leaflet/Mapbox 点图、热力图、聚合图 |
| 注册州到活动州 | Sankey 图、Chord 图 |
| 机场航线流量 | OD Flow Map、网络图 |
| 机龄和事故 | 热力矩阵、箱线图 |
| 区域画像 | 雷达图、平行坐标、聚类散点 |
| 关系网络 | Neo4j Bloom 风格网络图、中心性排行 |
| 相似案例 | Milvus Top-K 卡片、相似度分布图 |

### 六、优先级建议

最推荐先做“注册地偏离 + 机场承压 + 安全相似案例”三件事，因为它们能最大化利用当前已有数据：

1. FAA + OpenSky Trino + NASR：先得到真实活动地和机场基础设施承压。
2. FAA + NTSB + Milvus：再得到机型、机龄、事故叙述的风险画像和相似案例检索。
3. 全部实体关系进入 Neo4j：最后形成可解释的跨源关系网络，用路径和中心性支撑辅助决策。

最终表达可以进一步收束为：

> 以 FAA 注册飞机为航空资产底座，以 OpenSky 历史轨迹识别真实活动，以 NASR 衡量机场基础设施，以 BTS 衡量商业航空流量，以 NTSB 和 Milvus 识别安全语义风险，以 Neo4j 构建跨数据源实体关系网络，形成面向区域航空经济、机场承压、安全风险和资产流动的可视化辅助决策系统。
