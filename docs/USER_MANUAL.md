## 1. 项目简介

**数据安全动态采集系统** 是一款桌面应用程序，主要用于航空数据的采集、存储、分析和可视化展示。

本系统适合以下用户使用：

- 航空安全研究人员：通过 NTSB 事故趋势分析了解航空事故的分布、趋势和原因分类。
- 航空数据爱好者：查看全球实时航班分布，并匹配美国 FAA 飞机的注册信息。
- 数据分析学习者：了解如何从多个外部数据源下载、解析、入库数据，并在统一界面中进行聚合分析。

系统的主要功能包括：

- **航班地图**：在地图上查看全球航班分布，点击航班可查看详细的飞行数据（位置、速度、高度等）以及 FAA 注册信息（飞机型号、所有人等）。
- **事故分析**：浏览 NTSB（美国国家运输安全委员会）航空事故数据库的趋势图表、空间分布和分类统计。
- **数据采集**：从 OpenSky、FAA、NTSB 三个数据源下载、解析、导入数据到本地数据库。
- **用户管理**：支持多用户账号的创建、编辑、密码管理和删除。

## 2. 运行环境要求

### 操作系统

- **Windows**：Windows 10 或更高版本（64 位）。本系统当前只支持 Windows 平台。
- 其他操作系统（macOS、Linux）：当前版本未提供官方打包支持，但可通过源码运行（需自行安装 Node.js 环境）。

### 软件依赖

- **Node.js**：如需从源码运行或开发，建议安装 Node.js 18 或更高版本。如果仅使用打包后的 `.exe` 程序，则无需安装 Node.js。
- **网络连接**：首次使用时需要网络连接以下载外部数据源（OpenSky、FAA、NTSB）和加载地图瓦片。
- **本地存储空间**：程序运行需要足够的磁盘空间用于存储数据库和缓存文件。FAA 和 NTSB 数据文件较大，建议预留至少 2 GB 空间。

### 其他说明

- 本系统**不需要**安装额外的数据库软件。所有数据存储在程序自带的 SQLite 数据库文件中（`data/app.db`）。
- 本系统**不需要**安装 pandoc 或其他文档转换工具。
- 地图功能依赖 OpenStreetMap 瓦片服务，需要能够访问 `tile.openstreetmap.org`。

## 3. 安装与启动

### 方式一：使用打包后的可执行程序（推荐）

1. 获取 `数据安全动态采集系统.exe` 文件。
2. 双击运行即可。程序首次启动时会自动在程序所在目录创建 `data/` 文件夹用于存储数据。

### 方式二：从源码运行

如果您获取了项目源代码，请按以下步骤操作：

1. **克隆或解压项目**

   将项目文件放置到本地目录。

2. **安装依赖**

   打开命令行终端（PowerShell 或命令提示符），进入项目根目录，执行：

   ```bash
   npm install
   ```

   > **注意**：安装过程中会自动执行 `electron-builder install-app-deps`，用于编译原生模块（better-sqlite3）。如果该步骤失败，请参考 [常见问题 FAQ](#7-常见问题-faq)。

3. **启动程序**

   ```bash
   npm start
   ```

   程序将启动 Electron 窗口并加载登录界面。

### 方式三：构建打包版本

如果您需要生成可分发的 `.exe` 程序：

```bash
npm run build
```

构建成功后，可执行文件将输出到 `dist/` 目录。

> **注意**：Windows 下打包时如遇到 `winCodeSign` 相关权限错误，建议在 Windows 设置中开启"开发者模式"，或使用管理员权限运行构建命令。

## 5. 功能操作说明

### 5.1 用户登录与注销

#### 功能说明

系统启动后首先显示登录界面。用户必须输入正确的用户名和密码才能进入主界面。系统支持"保持登录"功能，即在关闭程序前如果未手动注销，下次启动时会自动恢复登录状态。

#### 操作步骤

1. 启动程序后，登录界面会自动显示。
2. 输入用户名和密码。
3. 点击 **"登 录"** 按钮（或按键盘回车键）。
4. 登录成功后，登录界面会自动消失，显示主界面。

**首次使用：**

如果系统中还没有任何用户账号，登录界面会显示提示信息：

> 初始账号：admin，密码：admin123

请使用该初始账号登录。登录后建议立即修改密码（参见 [5.5 系统管理](#55-系统管理用户管理)）。

**注销登录：**

点击界面右上角的 **"注销"** 按钮即可退出登录，返回登录界面。

**自动恢复登录：**

如果您上次关闭程序时未手动注销，下次启动时会自动跳过登录界面。如需切换用户，请先注销再使用其他账号登录。

#### 注意事项

- 初始管理员密码（`admin123`）仅用于首次登录，登录后请在"系统管理"中修改密码以确保安全。
- 密码使用 bcrypt 加密存储，不会以明文形式保存。
- 系统同一时间只支持一个会话（即一台电脑上只能有一个用户处于登录状态）。

### 5.2 数据采集入库

#### 功能说明

"数据采集入库"页面用于管理三个外部数据源的完整数据流程：**下载 → 解析 → 入库**。这是使用其他分析功能的前提步骤——在查看航班地图或 NTSB 事故分析之前，需要先在此页面导入相应的数据。

系统支持三种数据源：

| 数据源 | 标识 | 主要内容 |
|--------|------|----------|
| **OpenSky 全量航班状态数据** | `opensky_states` | 全球实时航班位置、速度、高度等信息 |
| **FAA 注册飞机数据库** | `faa_aircraft` | 美国注册飞机的型号、所有人、注册号等信息 |
| **美国民航事故调查数据集** | `ntsb_aviation_accidents` | NTSB 航空事故事件、涉事飞机、原因分析等 |

#### 操作步骤

**分步操作：**

1. 切换到 **"数据采集入库"** 标签页。
2. 在要操作的数据源卡片上，依次点击：
   - **"下载"** —— 从网络下载原始数据文件到本地。
   - **"解析"** —— 将下载的原始文件解析为结构化数据。
   - **"入库"** —— 将解析后的数据写入本地 SQLite 数据库。
3. 观察卡片上的状态变化：正在操作时按钮会禁用，操作完成后状态信息会更新。

**一键更新（推荐）：**

1. 切换到 **"数据采集入库"** 标签页。
2. 在目标数据源卡片上，直接点击 **"一键更新"** 按钮。
3. 系统会自动依次执行"下载 → 解析 → 入库"三个步骤。
4. 操作过程中会显示加载遮罩层，完成后会显示提示信息。

#### 结果说明

- 每张卡片上会显示：
  - **最近下载** 时间
  - **最近解析** 时间
  - **最近入库** 时间
  - **数据库记录数** —— 当前已入库的数据条数
- 操作成功时，状态显示为"就绪"；失败时会显示红色错误提示。

#### 注意事项

- **必须先下载才能解析**，必须先解析才能入库。"一键更新"会自动按正确顺序执行。
- FAA 数据文件（约 500 MB 压缩包）和 NTSB 数据文件下载时间较长，取决于网络速度，请耐心等待。
- 每次入库会**清空对应数据表中已有的全部数据**，然后写入新数据，因此不会产生重复记录。
- 如果某个步骤失败，请检查卡片上的错误提示，常见原因包括：网络连接失败、磁盘空间不足、原始数据文件未下载。
- 您无需每次使用都重新导入数据。如果只是想查看已有数据，可以跳过此页面，直接在分析页面点击"刷新分析数据"。

### 5.3 FAA/OpenSky 航班分析

#### 功能说明

在交互式地图上查看全球航班的实时位置分布，并通过 FAA 数据库匹配每架飞机的注册信息。已匹配 FAA 的航班用红色标识，未匹配的用蓝色标识。

#### 操作步骤

**查看航班地图：**

1. 确保已在"数据采集入库"页面导入了 **OpenSky** 和 **FAA** 数据（至少需要 OpenSky 数据）。
2. 切换到 **"FAA/OpenSky 分析"** 标签页。
3. 点击工具栏上的 **"刷新分析数据"** 按钮，从本地数据库加载航班数据。
4. 地图上会显示航班图标。可以使用鼠标滚轮缩放地图，拖拽平移视角。

**查看航班详情：**

1. 在地图上点击一个航班图标（飞机形状的标记）。
2. 右侧面板会显示该飞机的 **FAA 注册信息**（如有匹配）：
   - 注册号（N-NUMBER）
   - 所有人名称（NAME）
   - 所在城市/州/国家
   - 制造年份
   - 飞机型号
   - 发动机型号
   - 认证类型
   - 状态代码
   - 到期日
   - 等
3. 底部详情栏会显示该航班的 **OpenSky 原始字段**：
   - ICAO 24 位地址（icao24）
   - 呼号（callsign）
   - 来源国家（origin_country）
   - 位置更新时间
   - 最后联系时间
   - 经纬度
   - 气压高度（baro_altitude）
   - 是否在地面（on_ground）
   - 速度（velocity）
   - 航向（true_track）
   - 垂直速率（vertical_rate）
   - 传感器数量
   - 几何高度（geo_altitude）
   - 应答机代码（squawk）
   - 等

**取消选中：**

- 点击底部详情栏右侧的 **✕** 按钮。
- 或直接按键盘 **Esc** 键。
- 或点击地图空白处。

#### 结果说明

- 工具栏会显示当前统计信息：
  - **航班总数**：当前快照中的航班数量
  - **FAA 匹配**：成功匹配到 FAA 注册信息的航班数量
  - **FAA 记录**：FAA 数据库中的总记录数
  - **快照时间**：当前数据快照的时间戳

- 地图右下方的图例说明了三种图标颜色：
  - **红色**（已匹配 FAA）—— 该航班的 ICAO 24 位地址在 FAA 数据库中找到对应记录
  - **蓝色**（未匹配 FAA）—— 该航班没有对应的 FAA 注册信息
  - **黄色**（已选中）—— 当前点击选中的航班

#### 注意事项

- 分析页面**只读取本地数据库**，不会自动从互联网获取新数据。如需更新数据，请先到"数据采集入库"页面重新导入 OpenSky 数据。
- 并非所有航班都能匹配 FAA 信息。FAA 数据库仅包含在美国注册的飞机，因此美国以外的飞机通常无法匹配。
- 匹配依据是航班的 **icao24**（Mode S 24 位地址）与 FAA 数据库中的 **MODE S CODE HEX** 进行比对。
- 航班数据是某一时刻的**快照**，不是实时更新的。快照时间显示在工具栏上。

### 5.4 NTSB 事故趋势分析

#### 功能说明

基于 NTSB（美国国家运输安全委员会）航空事故数据库，提供多维度的事故趋势分析和可视化。包括关键指标概览、年度趋势图、严重度分布、地理空间聚合、飞机画像、天气光照分析和原因发现分类。

#### 操作步骤

**查看分析数据：**

1. 确保已在"数据采集入库"页面导入了 **NTSB** 数据。
2. 切换到 **"NTSB 事故趋势分析"** 标签页（默认首页即为该页面）。
3. 系统会自动加载聚合数据并渲染分析图表。

**使用筛选条件：**

页面顶部工具栏提供了多种筛选下拉框：

- **起始年份 / 结束年份**：按事故发生的年份范围筛选。
- **国家**：按事故发生的国家/地区筛选。
- **州/地区**：按事故发生的美国州或地区筛选。
- **严重度**：按最高伤害等级筛选（致命、严重、轻伤、无伤、未知）。
- **飞机类别**：按航空器类别筛选（飞机、直升机、滑翔机等）。
- **损坏程度**：按飞机损坏程度筛选（彻底毁坏、严重损坏、轻微损坏等）。

修改任意筛选条件后，所有图表会自动刷新。

**交互操作：**

- **点击年度趋势图中的柱状条**：将该年份设为筛选条件。
- **点击严重度分布条**：按该严重度筛选。
- **点击空间聚合地图上的圆圈**：按该区域（国家/州）筛选。
- **点击飞机类别/制造商**：按该类别或制造商筛选。

**重置筛选：**

点击工具栏右侧的 **"重置"** 按钮，恢复默认范围（全部年份、全部类别等）。

#### 结果说明

分析页面包含以下区域：

1. **关键指标（KPI）卡片**：
   - 总事故/事件数量
   - 致命事故数量
   - 致命占比
   - 涉事飞机总数
   - 有坐标信息的事故数
   - 有叙述文本的事故数
   - 事故高发地区

2. **年度事故趋势图**：柱状图显示每年事故总量，折线图显示致命事故趋势。点击柱条可按年份筛选。

3. **伤害严重度结构**：按最高伤害等级（致命/严重/轻伤/无伤）分布显示。

4. **事故空间聚合地图**：在地图上以圆圈大小表示各区域事故密度，圆圈颜色深浅表示致命率高低。点击圆圈可按区域筛选。

5. **飞机画像**：
   - 类别分布（飞机/直升机/滑翔机等）
   - 制造商 Top N 排行

6. **光照与天气**：按光照条件（白天/夜间/黎明/黄昏）和气象条件（目视/仪表）展示事故数和致命占比。

7. **原因发现分类**：对事故调查报告中的原因关键词进行粗分类展示。

#### 注意事项

- NTSB 数据需要先在"数据采集入库"页面导入。如果未导入数据，分析页面将没有数据可供显示。
- 筛选条件可组合使用。例如：同时筛选"2010-2020 年"+"直升机"+"致命事故"，即可聚焦于特定子集。
- 空间聚合基于事故记录的经纬度坐标。部分记录可能缺少精确坐标。
- NTSB 数据来源于美国 NTSB 公开数据库，以美国境内事故为主，但也包含部分国际合作调查数据。
- 数据更新频率取决于 NTSB 官方发布周期，通常每年更新一次。

### 5.5 系统管理（用户管理）

#### 功能说明

管理系统用户账号，支持新建用户、编辑用户名、修改密码、重置密码、删除用户、按用户名搜索和分页浏览。

#### 操作步骤

**查看用户列表：**

1. 切换到 **"系统管理"** 标签页。
2. 用户列表会以表格形式展示，包括：ID、用户名、角色、创建时间、最后登录时间。
3. 每页显示 20 条记录，底部可翻页。

**新建用户：**

1. 点击 **"新建用户"** 按钮。
2. 在弹出的对话框中输入用户名和密码。
3. 点击 **"保存"**。

**编辑用户：**

1. 在用户列表中，找到目标用户，点击其所在行的 **"编辑"** 按钮。
2. 在弹出的对话框中修改用户名（密码可选，留空则不修改密码）。
3. 点击 **"保存"**。

**重置密码：**

1. 在用户列表中，找到目标用户，点击其所在行的 **"重置密码"** 按钮。
2. 在弹出的对话框中输入新密码。
3. 点击 **"确认重置"**。

**删除用户：**

1. 在用户列表中，找到目标用户，点击其所在行的 **"删除"** 按钮。
2. 在确认对话框中点击 **"确认删除"**。

**搜索用户：**

1. 在搜索框中输入用户名关键词。
2. 点击 **"搜索"** 按钮或按回车键。

#### 注意事项

- **不能删除当前登录的账号**。如果尝试删除自己，系统会提示"不能删除当前登录账号"。
- **系统至少需要保留一个账号**。如果系统中只有一个用户，该用户无法被删除。
- 所有用户角色均为 `admin`（管理员），当前版本不区分普通用户和管理员权限。
- 密码使用 bcrypt 加密存储，即使是管理员也无法查看其他用户的明文密码。
- 关闭任意弹窗可以按 **Esc** 键，或点击弹窗外的灰色遮罩区域。

---

### 5.6 清理缓存

#### 功能说明

清除 `data/` 目录下的原始缓存文件（如原始 JSON、ZIP 文件等），但**不会**删除数据库文件（`app.db`）。

#### 操作步骤

1. 切换到 **"数据采集入库"** 标签页。
2. 点击工具栏右上角的 **"清理缓存"** 按钮。
3. 系统会显示清理了多少个缓存项。

#### 注意事项

- 清理缓存后，如果再次使用"下载"功能，系统会重新从网络获取数据文件。
- 清理缓存**不会**影响已入库的数据库数据，分析功能可正常使用。

## 6. 数据来源与刷新说明

### 数据来源

本系统使用以下三个外部数据源：

| 数据源 | 来源 | 内容 |
|--------|------|------|
| **OpenSky Network** | `https://opensky-network.org/api/states/all` | 全球范围内的航班实时状态数据，包括位置、速度、高度、呼号等。数据由志愿者网络接收 ADS-B 信号贡献。 |
| **FAA Registry** | `https://registry.faa.gov/database/ReleasableAircraft.zip` | 美国联邦航空管理局（FAA）维护的民用飞机注册数据库，包含美国境内注册飞机的详细信息。 |
| **NTSB Aviation Database** | `https://data.ntsb.gov/avdata/` | 美国国家运输安全委员会（NTSB）发布的航空事故和事件调查数据库。 |

### 数据刷新方式

- 系统**不会自动刷新数据**。所有数据需要用户主动在"数据采集入库"页面手动下载和导入。
- 数据刷新流程为：**下载原始文件 → 解析结构化数据 → 写入本地数据库**。
- 您可以选择单独执行每个步骤，也可以使用"一键更新"自动完成全部步骤。

### 数据存储位置

- 数据库文件：`data/app.db`（SQLite 格式）
- 原始缓存文件：`data/` 目录下的 `.json`、`.zip` 等文件
- 打包版程序中，`data/` 目录位于 `.exe` 文件所在的同级目录
- 源码版中，`data/` 目录位于项目根目录

### 数据字段说明

**OpenSky 航班状态主要字段：**

| 字段 | 含义 |
|------|------|
| icao24 | ICAO 24 位飞机地址（唯一标识） |
| callsign | 航班呼号 |
| origin_country | 来源国家 |
| longitude / latitude | 经度 / 纬度 |
| baro_altitude | 气压高度（米） |
| velocity | 地速（米/秒） |
| true_track | 真航向（度） |
| vertical_rate | 垂直速率（米/秒） |
| on_ground | 是否在地面 |

**FAA 注册信息主要字段：**

| 字段 | 含义 |
|------|------|
| N-NUMBER | 飞机注册号（N 编号） |
| NAME | 注册所有人名称 |
| CITY / STATE / COUNTRY | 所在城市 / 州 / 国家 |
| YEAR MFR | 制造年份 |
| TYPE AIRCRAFT | 飞机型号 |
| TYPE ENGINE | 发动机型号 |
| MODE S CODE HEX | Mode S 十六进制代码 |
| STATUS CODE | 注册状态代码 |
| EXPIRATION DATE | 注册到期日 |

**NTSB 事故数据主要维度：**

| 维度 | 含义 |
|------|------|
| 事故总数 | 符合条件的航空事故事件总数量 |
| 致命事故 | 至少造成 1 人死亡的事故 |
| 致命占比 | 致命事故占总事故的比例 |
| 严重度 | 最高伤害等级（致命/严重/轻伤/无伤） |
| 飞机类别 | 航空器类型（飞机/直升机/滑翔机等） |
| 损坏程度 | 飞机损坏等级（彻底毁坏/严重损坏/轻微损坏） |

### 网络失败时的处理

- 如果下载过程中网络中断，卡片上会显示错误提示。您可以再次点击"下载"重试。
- 已完成入库的数据不会因网络问题丢失，因为分析功能只读取本地数据库。
- 地图瓦片（OpenStreetMap）加载失败时，地图可能显示为灰色或部分缺失。请检查网络连接后重新切换回该页面。

### 数据不是实时的

- 航班数据是从 OpenSky 下载的**某一时刻的快照**，不是实时流式数据。快照时间会在 FAA/OpenSky 分析页面的工具栏上显示。
- 如需获取更新的航班数据，请在"数据采集入库"页面重新导入 OpenSky 数据。

## 7. 常见问题 FAQ

### Q1：程序无法启动怎么办？

**可能原因**：
- 依赖未正确安装（源码运行方式）。
- 杀毒软件拦截了 Electron 程序。
- `better-sqlite3` 原生模块未编译。

**解决办法**：
1. 如果是源码运行，请确保已执行 `npm install` 且没有报错。
2. 尝试重新执行 `npm install`。
3. 检查终端输出中的错误信息，根据具体错误进行排查。
4. 如果是打包后的 `.exe` 无法启动，尝试暂时关闭杀毒软件或将程序目录加入白名单。

---

### Q2：npm install 失败怎么办？

**可能原因**：
- Node.js 版本过低。
- 网络问题导致依赖下载失败。
- 原生模块编译缺少必要的构建工具（如 Visual Studio Build Tools）。

**解决办法**：
1. 确认 Node.js 版本为 18 或更高：`node --version`。
2. 如果网络较慢，可尝试配置 npm 镜像源（如使用 `nrm` 或手动设置 registry）。
3. 在 Windows 上编译原生模块需要安装 Visual Studio Build Tools 或 `windows-build-tools`：
   ```bash
   npm install --global windows-build-tools
   ```
   或者单独安装 Visual Studio 2022 Community Edition，并在安装时勾选"使用 C++ 的桌面开发"工作负载。
4. 删除 `node_modules` 文件夹后重新安装：
   ```bash
   rm -rf node_modules
   npm install
   ```

---

### Q3：地图不显示怎么办？

**可能原因**：
- 网络无法访问 OpenStreetMap 瓦片服务器。
- 页面初始化时地图容器尺寸为 0。

**解决办法**：
1. 确认计算机可以访问 `tile.openstreetmap.org`（可在浏览器中打开该网址测试）。
2. 切换到"FAA/OpenSky 分析"标签页，等待几秒让地图加载。如果之前在其他标签页，切换后地图会自动调整大小。
3. 检查 Windows 防火墙或代理设置是否阻止了程序的网络访问。
4. 如果地图瓦片仍然不显示，可能是 OpenStreetMap 服务器暂时不可用，请稍后重试。
5. 使用代理软件获得更好的网络环境。

---

### Q4：数据刷新失败怎么办？

**可能原因**：
- 网络连接不稳定或目标服务器不可用。
- 磁盘空间不足。
- 之前未下载原始数据就尝试解析。

**解决办法**：
1. 确认网络连接正常。可以在浏览器中打开数据源的 URL 进行测试。
2. 检查 `data/` 目录所在的磁盘是否有足够的可用空间。
3. 确保按照正确顺序操作：先"下载"，再"解析"，最后"入库"。如果不确定，请使用"一键更新"。
4. 查看卡片上的具体错误提示信息，根据提示进行针对性的排查。
5. 使用代理软件获得更好的网络环境。

---

### Q5：为什么有些飞机无法匹配 FAA 信息？

**可能原因**：
- FAA 数据库仅包含在美国注册的飞机。非美国注册的飞机不会出现在 FAA 数据库中。
- 某些飞机的 Mode S 代码在 FAA 数据库中可能以不同格式存储，导致匹配失败。
- FAA 数据未导入或导入不完整。

**解决办法**：
1. 确认已在"数据采集入库"页面导入了 FAA 数据。
2. 理解这是正常现象——地图上蓝色标识的飞机即为未匹配 FAA 的航班，这在全球航班中是大多数情况。
3. 如果某架您确认为美国注册的飞机未能匹配，可能 FAA 数据库尚未包含该注册信息，或 Mode S 地址格式存在差异。

---

### Q6：为什么数据不是实时变化的？

**说明**：
本系统不提供实时航班跟踪功能。地图上显示的航班数据是从 OpenSky 下载的**某一时刻的快照**。如果您想查看更新的航班数据，需要：

1. 切换到"数据采集入库"标签页。
2. 对 OpenSky 数据源执行"一键更新"。
3. 切换回"FAA/OpenSky 分析"页面，点击"刷新分析数据"。

系统设计上不支持自动刷新，所有数据更新需要用户手动触发。

---

### Q7：打包失败怎么办？

**可能原因**：
- Windows 下遇到 `winCodeSign` 解压符号链接权限错误。
- `electron-builder` 版本不兼容。

**解决办法**：
1. 在 Windows 设置中开启 **"开发者模式"**（设置 → 更新和安全 → 开发者选项 → 开发人员模式）。
2. 使用管理员权限运行命令提示符或 PowerShell，然后重新执行 `npm run build`。
3. 确保 `node_modules` 完整安装，可尝试删除后重装。
4. 打包输出目录为 `dist/`，如果该目录已存在旧版本文件，建议先清理。

### Q8：可以同时登录多个用户吗？

**不可以**。当前系统采用单会话模式，同一时间只允许一个用户登录。如果另一个用户需要登录，请先让当前用户注销。

**数据库位置**：

## 9. 使用建议与注意事项

### 数据刷新频率

- OpenSky 数据：建议根据分析需要按需刷新，不必高频更新。每次下载会消耗网络流量，且 OpenSky 免费 API 可能有频率限制。
- FAA 数据：该数据库更新频率较低（通常每月更新），不必频繁刷新。
- NTSB 数据：NTSB 官方数据更新频率约为每年一次，仅在需要最新年份数据时刷新即可。

### 网络请求限制

- **请勿频繁请求外部接口**。短时间内大量请求 OpenSky API 可能导致您的 IP 被暂时限制访问。
- 建议每次数据更新之间至少间隔数分钟。
- FAA 和 NTSB 数据文件较大（数百 MB），请确保在网络条件良好的情况下进行下载。

### 本地缓存管理

- `data/` 目录中的原始缓存文件（`.zip`、`.json`）在数据入库后可以安全删除，不会影响分析功能。
- 可以使用"清理缓存"功能一键清理。
- 数据库文件（`app.db`）会随着使用不断增大，如需清理空间，可以删除后重新导入数据。

### 隐私与合规

- 所有数据存储在您本地计算机的 `data/` 目录中，不会自动上传到任何服务器。
- OpenSky、FAA、NTSB 的数据均为公开数据集，使用时应遵守各数据源的使用条款。
- FAA 注册数据包含飞机所有人的姓名和地址信息，请勿将其用于商业目的或未经授权的个人信息收集。

### 数据用途声明

- 本系统提供的数据**仅供学习、研究或分析使用**，不应用于实际的航空导航或安全决策。
- 航班位置数据可能存在延迟或不准确，不能替代官方的航空管制信息。
- NTSB 事故分析结果仅反映历史统计数据，不具有预测意义。

### 其他建议

- 建议定期备份 `data/app.db` 文件，以防止数据丢失。
- 如果程序运行异常，可以尝试删除 `data/app.db` 以外的缓存文件，重新导入数据。
- 在大批量数据操作（如首次导入 NTSB 全量数据）时，建议关闭其他占用内存较大的程序。
