## 1. 项目简介

数据安全动态采集系统是一款桌面应用程序，用于航空数据的采集、存储、分析和可视化展示，也可服务于情报分析场景。

> 开源地址：[https://github.com/menelausx/Homework_ds](https://github.com/menelausx/Homework_ds)
>
> 发布地址：[https://github.com/menelausx/Homework_ds/releases/latest](https://github.com/menelausx/Homework_ds/releases/latest)

系统主要提供以下功能：

- **航班地图**：在地图上查看全球航班分布，点击航班可查看详细的飞行数据（位置、速度、高度等）以及 FAA 注册信息（飞机型号、所有人等）。
- **事故分析**：浏览 NTSB（美国国家运输安全委员会）航空事故数据库的趋势图表、空间分布和分类统计。
- **加密全文检索**：对 NTSB 事故叙述和原因发现文本进行加密关键词搜索，在不暴露明文的前提下完成文本检索。
- **数据采集**：从 OpenSky、FAA、NTSB 三个数据源下载、解析并导入数据到本地数据库。
- **用户管理**：支持多用户账号的创建、编辑、密码管理和删除。
- **密态存储**：所有敏感数据均采用应用层加密保护。数据库中的航班记录、FAA 注册信息、NTSB 事故数据及其分析维度使用 AES-256-GCM 加密；查询通过 HMAC-SHA-256 盲索引和加密倒排索引完成；下载缓存使用分块 AES-256-GCM 加密。加密和解密仅在 Electron 主进程中进行，渲染进程不接触密钥或明文解密能力。

> 由于采用密态存储，数据入库时需要对每条记录执行加密和盲索引计算，因此入库过程较为耗时（全量导入可能需要十几分钟），内存占用峰值超过 1 GB，最终生成的 `app.db` 文件大小约为 2 GB。请在导入数据前确保磁盘空间充足，并在操作期间耐心等待。

## 2. 安全架构概览

本系统采用应用层密态存储方案，对 SQLite 数据库和下载缓存实施全面的静态数据保护。以下从用户视角说明安全设计，帮助您理解数据如何被保护。

### 2.1 保护目标

系统的安全设计旨在防御攻击者单独获取以下静态文件后的数据泄露：

- `data/app.db`（SQLite 数据库文件）
- `data/app.db-wal` / `data/app.db-shm`（SQLite WAL 运行文件）
- 数据库备份
- `data/` 目录下的下载缓存文件（`.securecache`）
- 普通应用配置和日志

### 2.2 密钥体系

系统采用两级密钥管理，所有密钥操作通过 `src/main/security/keyService.js` 完成：

1. **主密钥**：首次启动时使用 `crypto.randomBytes(32)` 生成 256 位随机主密钥，通过操作系统安全能力封装后保存到 `data/keyring.json`。该文件仅包含封装后的主密钥和版本元数据，不包含明文密钥。
2. **子密钥派生**：通过 HKDF-SHA-256 从主密钥派生独立的业务子密钥。不同安全域（数据加密、用户名索引、ICAO/Mode-S 连接、NTSB 事件连接、分析维度索引、全文检索、缓存加密等）使用完全分离的密钥，防止跨字段关联。
3. **登录解锁**：用户密码通过 scrypt（N=32768, r=8, p=1）派生解锁密钥，用于解封 keyring 中的主密钥。密码同时通过 bcrypt（12 rounds）存储哈希，用于登录验证。
4. **密钥版本**：系统从第一版即支持 `key_version` 字段。新数据写入始终使用当前版本，解密时可按 envelope 中记录的版本选择对应密钥。

> **重要提示**：`keyring.json` 与 `app.db` 必须配套使用，来自同一套 `data/` 目录。单独替换或删除其中任意一个，将导致已存储数据无法解密。

### 2.3 数据加密方式

**数据库 payload 加密（AES-256-GCM）**：

- 每次加密生成独立的 96 位随机 nonce。
- 密文 envelope 包含格式版本、密钥版本、nonce、密文和认证标签。
- AAD（附加认证数据）绑定记录类型、字段名和记录标识，防止密文被跨表或跨字段替换。
- 解密认证失败时返回受控错误，不会返回乱码或部分数据。

**盲索引（HMAC-SHA-256）**：

- 精确查询、表连接和分组通过盲索引 token 完成：`token = HMAC-SHA-256(派生域密钥, 规范化值)`。
- 每种字段使用独立的规范化规则（如 ICAO 使用小写十六进制、州代码使用 trim + uppercase、文本使用 Unicode NFKC 规范化）。
- 数据库中仅存储 32 字节固定长度的 token BLOB，不保留明文字段。
- 相同值始终产生相同 token，支持等值匹配和 GROUP BY 聚合，但攻击者无法从 token 逆推原文。

**加密倒排索引**：

- 对 NTSB 事故叙述文本和原因发现文本进行分词后，每个规范化词条计算独立的 term token 并存入 `secure_terms` 表。
- 支持单关键词和多关键词 AND 检索，通过 token 集合交集完成。
- 查询时只需提供搜索关键词，系统在主进程中规范化并计算 token，再通过索引定位匹配记录，全程不扫描或解密全表。

**下载缓存加密（分块 AES-256-GCM）**：

- OpenSky JSON、FAA ZIP 和 NTSB ZIP 下载缓存使用独立缓存密钥进行分块加密，默认块大小为 1 MiB。
- 每块使用独立随机 nonce 和认证标签，AAD 绑定缓存 ID、块序号和原文长度。
- 文件头包含格式版本、密钥版本和块元数据，可检测篡改、截断、块重排和追加。
- 下载过程直接写入加密流，不在磁盘上产生明文临时文件。

### 2.4 可搜索加密的固有信息泄露

由于采用可搜索加密方案，攻击者在获取静态文件后可以看到以下信息——这是方案设计的内在特性，并非安全缺陷：

- 各表的规模、记录数量和密文长度级别。
- 相同盲索引 token 的等值关系（可推断"两个字段值相同"）以及查询访问模式。
- 查询结果数量、GROUP BY 分组频率和数据更新时间。
- 已明确保留的非敏感运行元数据（如快照时间戳）。

系统在设计上已为不同安全域分配独立 HMAC 密钥，以最大程度减少跨字段关联能力。

### 2.5 安全边界

- 加密与解密只发生在 Electron 主进程。渲染进程（前端界面）通过 `preload.js` 暴露的受限 IPC 接口获取业务结果，不能获得主密钥、派生密钥或通用解密能力。
- 前端无法直接访问 Node.js 文件系统、SQLite 数据库或原始网络请求。
- 密钥不得硬编码在源码中，不得保存在 SQLite、环境变量或普通明文配置中。
- 密码、密钥、查询 token 和完整密文不得写入日志。

## 3. 运行环境要求

### 操作系统

本系统当前只支持 Windows 平台，需要 Windows 10 或更高版本（64 位）。macOS 和 Linux 目前未提供官方打包支持，但可通过源码运行（需自行安装 Node.js 环境）。

### 软件依赖

- **Node.js**：如果从源码运行或进行开发，需要安装 Node.js 20 或兼容版本。如果只使用打包后的 `.exe` 程序，则无需安装 Node.js。
- **网络连接**：首次使用时需要网络连接以下载外部数据源（OpenSky、FAA、NTSB）和加载地图瓦片。
- **本地存储空间**：导入全部数据后，加密数据库文件（`app.db`）约占用 2 GB，加上下载缓存文件（`.securecache`），建议预留至少 3 GB 可用空间。如果仅导入部分数据源，可适当减少。

### 其他说明

- 本系统不需要安装额外的数据库软件。所有数据存储在程序自带的加密 SQLite 数据库文件（`data/app.db`）中，加密解密过程由程序自动完成，无需用户干预。
- 不需要安装 pandoc 或其他文档转换工具。
- 地图功能依赖 OpenStreetMap 瓦片服务，需要能够访问 `tile.openstreetmap.org`。

## 4. 安装与启动

### 方式一：使用打包后的可执行程序（推荐）

1. 从 [GitHub Releases](https://github.com/menelausx/Homework_ds/releases/latest) 页面下载最新版本的 `数据安全动态采集系统.exe` 文件。
2. 双击运行即可。程序首次启动时会自动在程序所在目录创建 `data/` 文件夹用于存储数据。

### 方式二：从源码运行

如果您获取了项目源代码，请按以下步骤操作：

1. **克隆或解压项目**

   从 GitHub 克隆项目源码：

   ```bash
   git clone https://github.com/menelausx/Homework_ds.git
   cd Homework_ds
   ```

   或者直接下载并解压源码压缩包，将项目文件放置到本地目录。

2. **安装依赖**

   打开命令行终端（PowerShell 或命令提示符），进入项目根目录，执行：

   ```bash
   npm install
   ```

   > 安装过程中会自动执行 `electron-builder install-app-deps`，用于编译原生模块（better-sqlite3）。如果该步骤失败，请参考[常见问题 FAQ](#8-常见问题-faq)。

3. **启动程序**

   ```bash
   npm start
   ```

   程序将启动 Electron 窗口并加载登录界面。

### 方式三：构建打包版本

如果您需要生成可分发的 `.exe` 程序：

```bash
npm run build
```

构建成功后，可执行文件将输出到 `dist/` 目录。

> Windows 下打包时如遇到 `winCodeSign` 相关权限错误，建议在 Windows 设置中开启"开发者模式"，或使用管理员权限运行构建命令。

## 6. 功能操作说明

### 6.1 用户登录与注销

#### 功能说明

系统启动后首先显示登录界面。用户必须输入正确的用户名和密码才能进入主界面。系统支持"保持登录"功能：勾选后，下次启动程序时可跳过登录界面直接进入。

#### 操作步骤

1. 启动程序后，登录界面会自动显示。
2. 输入用户名和密码。
3. （可选）勾选"保持登录"复选框，以便下次启动时自动恢复登录。
4. 点击"登 录"按钮（或按键盘回车键）。
5. 登录成功后，登录界面会自动消失，显示主界面。

**首次使用：**

如果系统中还没有任何用户账号，登录界面会显示提示信息：

> 初始账号：admin，密码：admin123

请使用该初始账号登录。登录后建议立即修改密码（参见[6.5 系统管理](#65-系统管理用户管理)）。

**注销登录：**

点击界面右上角的"注销"按钮即可退出登录，返回登录界面。

**自动恢复登录：**

如果登录时勾选了"保持登录"，下次启动程序时会自动跳过登录界面。保持登录凭据保存在 `data/login-session.json` 文件中。如需切换用户，请先注销再使用其他账号登录。

> 点击"注销"按钮会同时清除当前会话和保持登录凭据，下次启动时需要重新输入密码。

#### 注意事项

- 初始管理员密码（`admin123`）仅用于首次登录，登录后请在"系统管理"中修改密码以确保安全。
- 密码使用 bcrypt 加密存储，不会以明文形式保存。
- 系统同一时间只支持一个会话，即一台电脑上只能有一个用户处于登录状态。

### 6.2 数据采集入库

#### 功能说明

"数据采集入库"页面用于管理三个外部数据源的完整数据流程：下载 → 解析 → 入库。这是使用其他分析功能的前提——在查看航班地图或 NTSB 事故分析之前，需要先在此页面导入相应的数据。

系统支持三种数据源：

| 数据源 | 标识 | 主要内容 |
|--------|------|----------|
| OpenSky 全量航班状态数据 | `opensky_states` | 全球实时航班位置、速度、高度等信息 |
| FAA 注册飞机数据库 | `faa_aircraft` | 美国注册飞机的型号、所有人、注册号等信息 |
| 美国民航事故调查数据集 | `ntsb_aviation_accidents` | NTSB 航空事故事件、涉事飞机、原因分析等 |

#### 操作步骤

**分步操作：**

1. 切换到"数据采集入库"标签页。
2. 在要操作的数据源卡片上，依次点击"下载"→"解析"→"入库"。
3. 观察卡片上的状态变化：正在操作时按钮会禁用，操作完成后状态信息会更新。

**一键更新：**

1. 切换到"数据采集入库"标签页。
2. 在目标数据源卡片上，直接点击"一键更新"按钮。
3. 系统会自动依次执行下载 → 解析 → 入库三个步骤。
4. 操作过程中会显示加载遮罩层，完成后会显示提示信息。

#### 结果说明

每张卡片上会显示以下信息：

- 最近下载时间
- 最近解析时间
- 最近入库时间
- 数据库记录数（当前已入库的数据条数）

操作成功时，状态显示为"就绪"；失败时会显示红色错误提示。

#### 注意事项

- 必须先下载才能解析，必须先解析才能入库。"一键更新"会自动按正确顺序执行。
- FAA 数据文件（约 500 MB 压缩包）和 NTSB 数据文件下载时间较长，取决于网络速度，请耐心等待。
- 每次入库会清空对应数据表中已有的全部数据再写入新数据，因此不会产生重复记录。
- 如果某个步骤失败，请检查卡片上的错误提示。常见原因包括：网络连接失败、磁盘空间不足、原始数据文件未下载。
- 您无需每次使用都重新导入数据。如果只是想查看已有数据，可以跳过此页面，直接在分析页面点击"刷新分析数据"。

#### 关于入库耗时与资源占用

由于系统采用密态存储方案，入库过程并非简单的数据写入，而是需要对每一条记录执行 AES-256-GCM 加密、盲索引 token 计算（HMAC-SHA-256）以及加密倒排索引构建等大量密码学运算。这导致入库阶段会显著消耗计算资源和时间，具体表现如下：

- **耗时长**：全量导入单个数据源可能需要数分钟到十几分钟不等，三源全部导入耗时更长。入库过程中界面可能出现短暂无响应，这是正常现象，请勿强制关闭程序。
- **内存占用高**：入库期间，主进程需要同时处理原始数据解析、加密计算和数据库写入，内存峰值可能超过 1 GB。建议在入库前关闭其他占用内存较大的应用程序。
- **数据库体积大**：由于每条记录的 payload 均为加密后的密文（包含 nonce、认证标签等 envelope 开销），加上盲索引 token 和倒排索引表的存储，全部数据导入完成后 `data/app.db` 文件体积约为 2 GB。请确保 `data/` 所在磁盘至少有 3 GB 以上可用空间。

如果您只需要体验系统功能，可以只导入 OpenSky 数据（数据量较小、入库较快），FAA 和 NTSB 数据按需导入即可。

### 6.3 FAA/OpenSky 航班分析

#### 功能说明

在交互式地图上查看全球航班的实时位置分布，并通过 FAA 数据库匹配每架飞机的注册信息。已匹配 FAA 的航班用红色标识，未匹配的用蓝色标识。

#### 操作步骤

**查看航班地图：**

1. 确保已在"数据采集入库"页面导入了 OpenSky 和 FAA 数据（至少需要 OpenSky 数据）。
2. 切换到"FAA/OpenSky 分析"标签页。
3. 点击工具栏上的"刷新分析数据"按钮，从本地数据库加载航班数据。
4. 地图上会显示航班图标。可以使用鼠标滚轮缩放地图，拖拽平移视角。

**查看航班详情：**

## 7. 数据来源与刷新说明

### 数据来源

本系统使用以下三个外部数据源：

| 数据源 | 来源 | 内容 |
|--------|------|------|
| OpenSky Network | `https://opensky-network.org/api/states/all` | 全球范围内的航班实时状态数据，包括位置、速度、高度、呼号等。数据由志愿者网络接收 ADS-B 信号贡献。 |
| FAA Registry | `https://registry.faa.gov/database/ReleasableAircraft.zip` | 美国联邦航空管理局（FAA）维护的民用飞机注册数据库，包含美国境内注册飞机的详细信息。 |
| NTSB Aviation Database | `https://data.ntsb.gov/avdata/` | 美国国家运输安全委员会（NTSB）发布的航空事故和事件调查数据库。 |

### 数据刷新方式

- 系统不会自动刷新数据。所有数据需要用户主动在"数据采集入库"页面手动下载和导入。
- 数据刷新流程为：下载原始文件 → 解析结构化数据 → 写入本地数据库。
- 您可以选择单独执行每个步骤，也可以使用"一键更新"自动完成全部步骤。

### 数据存储位置

- 数据库文件：`data/app.db`（SQLite 密态数据库，所有敏感数据经过加密存储）
- 加密缓存文件：`data/` 目录下的 `.securecache` 文件（下载的原始数据以分块 AES-256-GCM 加密保存）
- 密钥文件：`data/keyring.json`（密钥管理系统文件，不包含明文主密钥）
- 会话文件：`data/login-session.json`（勾选"保持登录"后生成，不包含账号密码）
- 数据库运行文件：`data/app.db-wal`、`data/app.db-shm`（SQLite WAL 模式自动生成）
- 打包版程序中，`data/` 目录位于 `.exe` 文件所在的同级目录
- 源码版中，`data/` 目录位于项目根目录

> **重要提示**：`keyring.json` 与 `app.db` 必须配套使用。单独替换或删除其中任意一个，可能导致已存储的数据无法解密。如需迁移数据，请整体复制 `data/` 目录。

### 数据字段说明

**OpenSky 航班状态主要字段：**

| 字段 | 含义 |
|------|------|
| icao24 | ICAO 24 位飞机地址（唯一标识） |
| callsign | 航班呼号 |
| origin_country | 来源国家 |
| longitude / latitude | 经度 / 纬度 |
| baro_altitude | 气压高度（米） |
| velocity | 地速（米/秒） |
| true_track | 真航向（度） |
| vertical_rate | 垂直速率（米/秒） |
| on_ground | 是否在地面 |

**FAA 注册信息主要字段：**

| 字段 | 含义 |
|------|------|
| N-NUMBER | 飞机注册号（N 编号） |
| NAME | 注册所有人名称 |
| CITY / STATE / COUNTRY | 所在城市 / 州 / 国家 |
| YEAR MFR | 制造年份 |
| TYPE AIRCRAFT | 飞机型号 |
| TYPE ENGINE | 发动机型号 |
| MODE S CODE HEX | Mode S 十六进制代码 |
| STATUS CODE | 注册状态代码 |
| EXPIRATION DATE | 注册到期日 |

**NTSB 事故数据主要维度：**

| 维度 | 含义 |
|------|------|
| 事故总数 | 符合条件的航空事故事件总数量 |
| 致命事故 | 至少造成 1 人死亡的事故 |
| 致命占比 | 致命事故占总事故的比例 |
| 严重度 | 最高伤害等级（致命/严重/轻伤/无伤） |
| 飞机类别 | 航空器类型（飞机/直升机/滑翔机等） |
| 损坏程度 | 飞机损坏等级（彻底毁坏/严重损坏/轻微损坏） |

### 网络失败时的处理

- 如果下载过程中网络中断，卡片上会显示错误提示。您可以再次点击"下载"重试。
- 已完成入库的数据不会因网络问题丢失，因为分析功能只读取本地数据库。
- 地图瓦片（OpenStreetMap）加载失败时，地图可能显示为灰色或部分缺失。请检查网络连接后重新切换回该页面。

### 数据不是实时的

航班数据是从 OpenSky 下载的某一时刻的快照，不是实时流式数据。快照时间会在 FAA/OpenSky 分析页面的工具栏上显示。如需获取更新的航班数据，请在"数据采集入库"页面重新导入 OpenSky 数据。

## 8. 常见问题 FAQ

### Q1：程序无法启动怎么办？

可能原因：
- 依赖未正确安装（源码运行方式）。
- 杀毒软件拦截了 Electron 程序。
- `better-sqlite3` 原生模块未编译。

解决办法：
1. 如果是源码运行，请确保已执行 `npm install` 且没有报错。
2. 尝试重新执行 `npm install`。
3. 检查终端输出中的错误信息，根据具体错误进行排查。
4. 如果是打包后的 `.exe` 无法启动，尝试暂时关闭杀毒软件或将程序目录加入白名单。

---

### Q2：npm install 失败怎么办？

可能原因：
- Node.js 版本过低。
- 网络问题导致依赖下载失败。
- 原生模块编译缺少必要的构建工具（如 Visual Studio Build Tools）。

解决办法：
1. 确认 Node.js 版本为 20 或更高：`node --version`。
2. 如果网络较慢，可尝试配置 npm 镜像源（如使用 `nrm` 或手动设置 registry）。
3. 在 Windows 上编译原生模块需要安装 Visual Studio Build Tools 或 `windows-build-tools`：
   ```bash
   npm install --global windows-build-tools
   ```
   或者单独安装 Visual Studio 2022 Community Edition，并在安装时勾选"使用 C++ 的桌面开发"工作负载。
4. 删除 `node_modules` 文件夹后重新安装：
   ```bash
   rm -rf node_modules
   npm install
   ```

---

### Q3：地图不显示怎么办？

可能原因：
- 网络无法访问 OpenStreetMap 瓦片服务器。
- 页面初始化时地图容器尺寸为 0。

解决办法：
1. 确认计算机可以访问 `tile.openstreetmap.org`（可在浏览器中打开该网址测试）。
2. 切换到"FAA/OpenSky 分析"标签页，等待几秒让地图加载。如果之前在其他标签页，切换后地图会自动调整大小。
3. 检查 Windows 防火墙或代理设置是否阻止了程序的网络访问。
4. 如果地图瓦片仍然不显示，可能是 OpenStreetMap 服务器暂时不可用，请稍后重试。
5. 使用代理软件获得更好的网络环境。

---

### Q4：数据刷新失败怎么办？

可能原因：
- 网络连接不稳定或目标服务器不可用。
- 磁盘空间不足。
- 之前未下载原始数据就尝试解析。

解决办法：
1. 确认网络连接正常。可以在浏览器中打开数据源的 URL 进行测试。
2. 检查 `data/` 目录所在的磁盘是否有足够的可用空间。
3. 确保按照正确顺序操作：先"下载"，再"解析"，最后"入库"。如果不确定，请使用"一键更新"。
4. 查看卡片上的具体错误提示信息，根据提示进行针对性的排查。
5. 使用代理软件获得更好的网络环境。

---

### Q5：为什么有些飞机无法匹配 FAA 信息？

FAA 数据库仅包含在美国注册的飞机，非美国注册的飞机不会出现在 FAA 数据库中，因此地图上蓝色标识的航班占多数是正常现象。此外，某些飞机的 Mode S 代码可能在 FAA 数据库中以不同格式存储，导致匹配失败。

如果确认某架美国注册的飞机未能匹配，可能 FAA 数据库尚未包含该注册信息，或 Mode S 地址格式存在差异。请先确保已在"数据采集入库"页面导入了 FAA 数据。

### Q6：为什么数据不是实时变化的？

本系统不提供实时航班跟踪功能。地图上显示的航班数据是从 OpenSky 下载的某一时刻的快照。如需查看更新的数据，请按以下步骤操作：

1. 切换到"数据采集入库"标签页。
2. 对 OpenSky 数据源执行"一键更新"。
3. 切换回"FAA/OpenSky 分析"页面，点击"刷新分析数据"。

为符合上游开源项目要求，系统设计上不支持自动刷新，所有数据更新需要用户手动触发。

### Q7：打包失败怎么办？

可能原因：
- Windows 下遇到 `winCodeSign` 解压符号链接权限错误。
- `electron-builder` 版本不兼容。

解决办法：

1. 在 Windows 设置中开启"开发者模式"（设置 → 更新和安全 → 开发者选项 → 开发人员模式）。
2. 使用管理员权限运行命令提示符或 PowerShell，然后重新执行 `npm run build`。
3. 确保 `node_modules` 完整安装，可尝试删除后重装。
4. 打包输出目录为 `dist/`，如果该目录已存在旧版本文件，建议先清理。

不可以。当前系统采用单会话模式，同一时间只允许一个用户登录。如果另一个用户需要登录，请先让当前用户注销。

### Q10：忘记密码怎么办？

如果您是普通用户，请联系系统管理员（即拥有管理员权限的其他用户），请其在"系统管理"中重置您的密码。

如果您是唯一的管理员且忘记了密码：同时删除 `data/app.db`、`data/app.db-wal`、`data/app.db-shm` 和 `data/keyring.json` 文件，然后重新启动程序，系统将自动创建默认管理员账号 `admin / admin123`。

> 注意：这会永久清除所有用户数据和已导入的航班/FAA/NTSB 数据。不要只删除 keyring 而保留数据库，否则数据库将无法解密。

---

### Q11：程序窗口显示异常或界面错乱怎么办？

1. 尝试调整窗口大小（程序支持最小 1100×700 的分辨率）。
2. 如果窗口被拖动到屏幕外，可以尝试按 `Win + 方向键` 将窗口移动到可见区域。
3. 如果问题持续，关闭程序后重新启动。

---

### Q12：可以导入自己的数据吗？

当前版本不支持用户自定义数据导入。系统仅支持预设的三个数据源（OpenSky、FAA、NTSB）的下载和导入。

## 9. 错误提示与排查

| 问题现象 | 可能原因 | 解决办法 |
|----------|----------|----------|
| 启动时黑屏或白屏 | 渲染进程加载失败 | 重新启动程序；检查 `node_modules` 是否完整 |
| "用户名或密码错误" | 输入的用户名或密码不正确 | 检查输入是否正确（区分大小写）；如忘记密码请联系管理员 |
| "用户名不能为空" / "密码不能为空" | 新建用户或修改用户时未填写必填项 | 补全信息后重新提交 |
| "用户名已存在" | 尝试创建或修改为已存在的用户名 | 换一个不同的用户名 |
| "不能删除当前登录账号" | 试图删除自己正在使用的账号 | 先用其他账号登录再删除 |
| "系统至少需要保留一个账号" | 试图删除系统中最后一个用户 | 至少保留一个用户账号 |
| 下载失败 | 网络连接问题或目标服务器不可用 | 检查网络连接；稍后重试；确认目标 URL 可在浏览器中打开 |
| "原始数据缓存不存在，请先下载" | 未执行下载步骤就尝试解析 | 先点击"下载"，完成后再点"解析" |
| 解析失败 | 下载的文件损坏或不完整 | 清空失败文件后重新下载 |
| 入库失败 | 数据库写入权限问题或磁盘空间不足 | 检查磁盘空间；确认 `data/` 目录有写入权限 |
| 地图仅显示灰色背景 | OpenStreetMap 瓦片加载失败 | 检查网络连接（需能访问 tile.openstreetmap.org） |
| NTSB 页面图表无数据 | 未导入 NTSB 数据或筛选条件过严 | 先在数据采集入库中导入 NTSB 数据；尝试"重置"筛选条件 |
| 程序卡死或无响应 | 大量数据加载或 FAA 查询耗时 | 耐心等待；下次可尝试分步操作而非一键更新 |
| `better-sqlite3` 编译失败 | 缺少 C++ 编译工具链 | 安装 Visual Studio Build Tools 或 windows-build-tools |
| 打包时 `winCodeSign` 报错 | Windows 权限不足 | 开启开发者模式；或以管理员权限运行 |
| 登录失败但密码正确 | `keyring.json` 与 `app.db` 不配套 | 如果移动过 `data/` 目录，请确保 `keyring.json` 和 `app.db` 一起移动；不要只替换其中一个 |
| 导入的旧数据无法查看 | keyring 已更换或丢失 | 删除 `data/app.db` 和 `data/keyring.json` 后重启程序并重新导入数据 |

## 10. 使用建议与注意事项

### 数据刷新频率

- OpenSky 数据：建议根据分析需要按需刷新，不必高频更新。每次下载会消耗网络流量，且 OpenSky 免费 API 可能有频率限制。
- FAA 数据：该数据库更新频率较低（通常每月更新），不必频繁刷新。
- NTSB 数据：NTSB 官方数据更新频率约为每年一次，仅在需要最新年份数据时刷新即可。

### 网络请求限制

- 请勿频繁请求外部接口。短时间内大量请求 OpenSky API 可能导致您的 IP 被暂时限制访问。建议每次数据更新之间至少间隔数分钟。
- FAA 和 NTSB 数据文件较大（数百 MB），请确保在网络条件良好的情况下进行下载。

### 本地缓存管理

- `data/` 目录中的加密缓存文件（`.securecache`）在数据入库后可以安全删除，不会影响分析功能。您可以使用"清理缓存"功能一键清理。
- 数据库文件（`app.db`）会随着使用不断增大。如需清理空间，可以删除 `app.db` 和 `keyring.json` 后重新导入数据。注意：这会同时清除所有用户账号。

### 隐私与合规

- 所有数据存储在您本地计算机的 `data/` 目录中，不会自动上传到任何服务器。
- OpenSky、FAA、NTSB 的数据均为公开数据集，使用时应遵守各数据源的使用条款。
- FAA 注册数据包含飞机所有人的姓名和地址信息，请勿将其用于商业目的或未经授权的个人信息收集。

### 数据用途声明

- 本系统提供的数据仅供学习、研究或分析使用，不应用于实际的航空导航或安全决策。
- 航班位置数据可能存在延迟或不准确，不能替代官方的航空管制信息。
- NTSB 事故分析结果仅反映历史统计数据，不具有预测意义。

### 其他建议

- 建议定期备份 `data/app.db` 和 `data/keyring.json` 文件（两者必须一起备份），以防止数据丢失。
- 如果程序运行异常，可以尝试删除 `data/app.db` 以外的缓存文件，重新导入数据。
- 在大批量数据操作（如首次导入 NTSB 全量数据）时，建议关闭其他占用内存较大的程序。
